# Kinetic Precision & Dark Industrial

> Audio-reactive kinetic typography driven by a 4-phase procedural Web Audio engine (inspired by Strudel.js and live-coding algorave aesthetics) and p5.js canvas rendering.

---

## ⚡ Overview

- **Interactive Kinetic Canvas:** Swiss minimalist kinetic typography (Inter & JetBrains Mono) with dynamic tracking, 1px box crosshairs, and audio-reactive impact decay.
- **Procedural Web Audio Engine:** Pure synthesis (no external audio assets). Progresses across 4 structured phases:
  1. `01 // PULSE` — Minimal kick pulses & foundational spacing
  2. `02 // STRUCTURE` — Offbeat hi-hats, dynamic basslines & kinetic shifts
  3. `03 // KINETIC TECH` — High-speed glitches, datablips & slit animations
  4. `04 // DARK INDUSTRIAL` — Heavy 43.65 Hz detuned saw/triangle drone, sub impacts & dark deconstruction
- **Editorial Case Study:** Complete Swiss-style project documentation included in `case-study.html`.

## 🛠 Tech Stack

- **Graphics & Motion:** [p5.js](https://p5js.org/)
- **Sound Design:** Web Audio API (Oscillators, Biquad Filters, Procedural Noise Buffers, Waveshapers)
- **Tooling:** Vite, Vanilla JavaScript (ES6+), HTML5, CSS3

## 🚀 Quick Start

```bash
# Clone repository
git clone https://github.com/maxdoesborgh/kinetic-precision-strudel.git
cd kinetic-precision-strudel

# Start local dev server
npx vite
# or
npm run dev
```

Open `http://localhost:5173/` (or port indicated by Vite) to interact with the audio-kinetic engine.  
Open `http://localhost:5173/case-study.html` to view the design case study.
