Kinetic Precision & Dark Industrial — Audio-Reactive Web Engine

Creative Coding / Web Audio API / Generative Typography / Algorave Experiment
MAX DOESBORGH
43.65 HZ // DARK DRONE OVERLAY // SEISMIC ENGINE // 134.00 BPM
ONTWERPVISUALISATIE — RUNTIME AUDIOPLAYER EN KINETISCHE MATRIX
DOEL

Een interactieve browser-ervaring ontwikkelen waarin minimalistische Zwitserse typografie zich synchroon en synesthetisch gedraagt als een kinetisch precisie-instrument, gedreven door een meervoudige Web Audio synthesizer-engine die evolueert van gecontroleerde pulsen naar een rauwe, duistere industriële climax.

INSPIRATIE

Geïnspireerd door live-coding algorave performances op Instagram en de toevallige ontdekking van Strudel.js (het browser-gebaseerde TidalCycles live coding ecosysteem). De esthetiek combineert de modulaire precisie van pattern-based audio-architectuur met brute industriële techno en haarscherpe typografische choreografie.

PROCES & ITERATIEF PROMPTEN (VIBE CODING)
  1. Muzikale & Wiskundige Architectuur (Web Audio API & Strudel-principes): Gestart vanuit cyclische pattern-interactie op 134 BPM. De audio-engine is gestructureerd in 4 progressieve fasen (01 // Pulse, 02 // Structure, 03 // Kinetic Tech, en 04 // Dark Industrial). In plaats van statische audio-samples worden alle klanken programmatisch gegenereerd: punchy kicks met exponentiële frequentie-ramps, procedurale noise-buffers voor haarscherpe hi-hats, datablips en een diepe sub-drone op 43.65 Hz (F1/C1) met lichte detuning en low-pass resonantie (Q=8).
  2. Design-discipline & Typografische Rigor: Door scherpe prompting in Antigravity zijn typische AI-clichés (zoals regenboogkleuren, overdadige glow-filters en chaotische spectrum analyzers) resoluut geëlimineerd. Het visuele systeem handhaaft een strikt Zwitsers minimalistisch grid met 1px haarlijnen, crosshairs, en dynamische letter-spacing interpolatie (Inter 900) die reageert op exponentiële decay-waarden van de audio-impacts (kickImpact, hatImpact, darkDroneImpact).
  3. Fase-transities & Duistere Deconstructie: In de vierde fase transformeert de visuele taal drastisch: de koele blauwe accenten maken plaats voor donker leisteen en zilver, terwijl de typografie horizontaal openschuift via ademende deconstructie-contouren en snijlijnen die synchroon ademen met de seismische lage drone.
TOOLING & DEPLOYMENT PIPELINE
  1. Lokaal ontwikkelen met Vite & Fast HMR: Ontwikkeld met een lokale Vite dev-server. Vanwege unieke mapnamen met leestekens is de configuratie afgestemd via een maatwerk vite.config.js (server.fs.strict: false), waardoor de hot-reloading pipeline vlekkeloos en zonder serveerbeperkingen draait.
  2. Antigravity Agent Integratie: De code is stapsgewijs geëvolueerd in pair-programming met de agent: van modulaire Web Audio DSP-routing en micro-timing buffers tot wiskundig gekalibreerde p5.js animatiecurven in index.html.
  3. Deployment & Productiestandaard: Zero-dependency architectuur op de client (alle audio en graphics worden puur wiskundig berekend in Web Audio en p5.js). Volledig voorbereid op automatische CI/CD via GitHub en Vercel Edge voor vlekkeloze weergave in het portfolio.
TECHNIEK & STACK

HTML5, Vanilla JavaScript (ES6+), Web Audio API (Synthese, Custom Noise Buffers, Biquad Filters & WaveShaper), p5.js Canvas Rendering, Inter (400–900) & JetBrains Mono typografie, Vite.
